# คำแนะนำการตรวจสอบบอร์ด ESP32 (สำหรับผู้ถือบอร์ด - Friend-Side Package)

ชุดเครื่องมือนี้ใช้สำหรับตรวจสอบรายละเอียดของบอร์ด ESP32 ที่รับมาจากร้านค้า เพื่อให้ทีมวิศวกร GasGuard ล็อกสเปกบอร์ด (FQBN) และเตรียมไฟล์คอมไพล์เฟิร์มแวร์ได้อย่างถูกต้องและปลอดภัย

---

## ⚠️ ข้อควรระวังด้านความปลอดภัยทางไฟฟ้า (Electrical Safety First)

1. **เชื่อมต่อเฉพาะสาย USB เท่านั้น**: ก่อนเสียบบอร์ดกับคอมพิวเตอร์ **ถอดอุปกรณ์เสริมทั้งหมดออก** (เซนเซอร์ MQ-6, เซนเซอร์ MQ-3/MQ-2, รีเลย์, บัซเซอร์, วาล์วแก๊ส, อะแดปเตอร์ 12V)
2. **ห้ามจ่ายไฟภายนอก 5V/12V**: ให้บอร์ดรับไฟจากพอร์ต USB ของคอมพิวเตอร์เท่านั้นในขั้นตอนนี้
3. **ห้ามทำการทดสอบแก๊สหรือเปลวไฟ**: ขั้นตอนนี้เป็นการตรวจสอบพอร์ต USB / Serial เท่านั้น

---

## 📋 ขั้นตอนการทำงาน (Step-by-Step Workflow)

### ขั้นตอนที่ 1: เตรียมบอร์ดและสาย USB
- ใช้สาย USB ที่รองรับการรับส่งข้อมูล (**Data Cable**) เท่านั้น (ห้ามใช้สายชาร์จอย่างเดียว Charge-Only)
- หากไม่แน่ใจ ให้เตรียมสาย USB 2-3 เส้นไว้สำรอง

### ขั้นตอนที่ 2: รันสคริปต์ตรวจสอบอัตโนมัติ
1. ดับเบิลคลิกไฟล์ `detect-board.cmd` (หรือเปิด PowerShell แล้วรัน `.\detect-gasguard-board.ps1`)
2. หากต้องการให้ตรวจสอบเปรียบเทียบก่อน-หลังเสียบสาย:
   - รันสคริปต์ก่อนเสียบบอร์ด (เพื่อบันทึกพอร์ตที่มีอยู่เดิม)
   - เสียบบอร์ด ESP32 เข้ากับพอร์ต USB
   - กด **Enter** เพื่อให้สคริปต์ค้นหาอุปกรณ์ใหม่ (New Device Candidate)

### ขั้นตอนที่ 3: ตรวจสอบไฟล์รายงานที่สร้างขึ้น
เมื่อสคริปต์ทำงานเสร็จ จะสร้างไฟล์รายงาน 2 ไฟล์ในโฟลเดอร์นี้:
1. `gasguard-board-report.txt` (รายงานแบบข้อความอ่านง่าย)
2. `gasguard-board-report.json` (รายงานแบบโครงสร้างข้อมูล)

### ขั้นตอนที่ 4: ถ่ายรูปบอร์ดเพื่อยืนยัน (Physical Evidence)
ถ่ายรูปบอร์ด ESP32 ชัดๆ (ตัวอักษรบนชิปอ่านออกได้) ส่งกลับมาพร้อมกับไฟล์รายงาน:
1. **รูปด้านหน้าบอร์ด** (ภาพรวมทั้งหมด)
2. **รูปด้านหลังบอร์ด** (ภาพรวมและตัวอักษรสกรีนบนแผ่นปริ้นต์)
3. **รูปขยายโมดูลโลหะ RF** (ข้อความสกรีนบนฝาครอบโลหะ เช่น ESP-WROOM-32 / ESP32-WROVER)
4. **รูปขยายชิปแปลง USB-UART** (ชิปสี่เหลี่ยมเล็กๆ ใกล้พอร์ต USB เช่น CP2102, CH340G)
5. **รูปขยายป้ายกำกับขา (Pin Labels)** ทั้งสองฝั่งของบอร์ด
6. **รูปขยายโมดูลเซนเซอร์แก๊สตัวที่สอง** (ถ่ายสกรีนโมดูลให้เห็นชัดว่าเป็น MQ-3 หรือ MQ-2)

## 🔍 การแก้ปัญหาเบื้องต้น (Troubleshooting)

- **หากรายงานขึ้นสถานะ `AMBIGUOUS_DEVICE_SELECTION` (พอร์ต COM ซ้ำซ้อน)**:
  - ถอดสาย USB ของ ESP32 ออกก่อน
  - รันสคริปต์ใหม่อีกครั้ง
  - เลือกรอบแบบ **BEFORE / AFTER** (พิมพ์ Y)
  - เสียบสาย USB ของ ESP32 เมื่อสคริปต์แจ้งให้เสียบ
  - กด Enter เพื่อให้สคริปต์ระบุพอร์ตอุปกรณ์ใหม่อย่างแม่นยำ

- **เสียบสายแล้วไม่มีเสียงตึ๊ด หรือไม่มี COM Port ขึ้น**:
  - ลองเปลี่ยนสาย USB (สายอาจเป็นสายชาร์จอย่างเดียว ไม่มีสายสัญญาณ Data)
  - ลองเปลี่ยนพอร์ต USB บนคอมพิวเตอร์
  - หาก Windows ขึ้นอัศเจรีย์สีเหลืองใน Device Manager แสดงว่ายังไม่ได้ลงไดรเวอร์ (เช่น CP210x หรือ CH340) ให้แจ้งทีมวิศวกรเพื่อขอไดรเวอร์ที่ถูกต้อง
