# GasGuard UI Review Checklist

Use the Review context bar in every capture and record the Page, Role, Scenario and viewport with each comment.

- อ่านสถานะปัจจุบันและสิ่งที่ควรทำต่อได้หรือไม่
- สี, label และ contrast แยก Safe, Watch, Danger, Unknown และ System Fault ได้หรือไม่
- ข้อมูลมากหรือน้อยเกินไปสำหรับ role นี้หรือไม่
- ปุ่มเด่นคือ action ที่เหมาะสมหรือไม่
- ลำดับข้อมูลและภาษาไทยอ่านเข้าใจง่ายหรือไม่
- Desktop และ mobile มีข้อความตัด, overflow หรือ action หลุดจอหรือไม่
- General เห็นเฉพาะข้อมูลที่จำเป็น และ Developer เห็นหลักฐานได้ครบหรือไม่
- Incident, request, verification และ report มี relation ที่เข้าใจได้หรือไม่
- มีจุดสับสน หรือสิ่งที่อยากเพิ่ม/ลดอะไรบ้าง
