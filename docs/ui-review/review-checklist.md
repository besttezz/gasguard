# GasGuard UI Review Checklist

Use the Review context bar in every capture and record the Page, Role, Scenario and viewport with each comment.

1. อ่านสถานะปัจจุบันออกหรือไม่ และรู้ว่าต้องทำอะไรต่อหรือไม่
2. ข้อมูลสำคัญเด่นพอหรือไม่ และข้อมูลมากเกินไปสำหรับ role นั้นหรือไม่
3. สี, label และ contrast แยก Safe, Watch, Danger, Unknown และ System Fault ได้หรือไม่
4. ภาษาไทยเข้าใจง่ายหรือไม่ และปุ่มอยู่ในตำแหน่งที่คาดหวังหรือไม่
5. General เห็นเฉพาะข้อมูลที่จำเป็น และ Developer เห็นหลักฐานได้ครบหรือไม่
6. Incident, request, verification และ report มี relation ที่เข้าใจได้หรือไม่
7. Desktop มีข้อความตัด, overflow, card/table ดันหน้า หรือ action หลุดจอหรือไม่
8. Mobile มี drawer ทับเนื้อหา, ปุ่มสำคัญหาย หรือเนื้อหาล้นแนวนอนหรือไม่
9. ควรเพิ่มอะไร ควรตัดอะไร และมีจุดใดสับสน
