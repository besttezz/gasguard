# เปิดใช้แจ้งเตือน LINE และสรุปสัปดาห์ด้วย AI

แอปทำงานได้ตั้งแต่ยังไม่ตั้งค่า 2 อย่างนี้:
- **LINE:** ในแอปจะขึ้นว่า "ยังไม่ได้ตั้งค่า"
- **AI:** ระบบจะใช้สรุปแบบเทมเพลตแทน

คีย์ทุกตัวเป็นของคุณ ให้ตั้งเองด้วยคำสั่งด้านล่าง **ห้ามส่งคีย์ในแชท** และห้ามใส่ใน git

## 1. LINE Official Account (แจ้งเตือนแม้ไม่ได้เปิดแอป)

1. เข้า <https://developers.line.biz/console/> แล้วล็อกอินด้วยบัญชี LINE
2. สร้าง Provider จากนั้นสร้าง Channel แบบ **Messaging API** (ระบบจะสร้าง LINE OA ให้ด้วย)
3. แท็บ **Basic settings**: คัดลอก **Channel secret**
4. แท็บ **Messaging API**:
   - กด Issue **Channel access token (long-lived)** แล้วคัดลอกไว้
   - ช่อง **Webhook URL** ใส่ `https://gasguard-bu.pages.dev/api/v1/line/webhook` กด Verify แล้วเปิด **Use webhook**
   - ปิด **Auto-reply messages** และ **Greeting messages** (ใน LINE Official Account Manager)
   - คัดลอกลิงก์เพิ่มเพื่อน (รูปแบบ `https://lin.ee/...`) จาก QR code / Add friend
5. ตั้งค่าใน Cloudflare โดยรันในโฟลเดอร์โปรเจกต์ทีละคำสั่ง (โปรแกรมจะถามค่า ให้วางค่าที่คัดลอกไว้):

```powershell
npx.cmd wrangler pages secret put LINE_CHANNEL_SECRET --project-name gasguard-bu
npx.cmd wrangler pages secret put LINE_CHANNEL_ACCESS_TOKEN --project-name gasguard-bu
```

6. ใส่ลิงก์เพิ่มเพื่อน (ไม่ใช่ความลับ) ใน `wrangler.toml` ใต้ `[vars]`: `LINE_ADD_FRIEND_URL = "https://lin.ee/xxxx"` แล้ว deploy ใหม่

**วิธีใช้:**
- สมาชิกเข้าไปที่ **บ้านของฉัน > เชื่อม LINE** แล้วเพิ่มเพื่อน
- ส่งรหัส 6 หลักที่แอปให้ไปในแชท LINE
- ระบบจะแจ้งเตือนเมื่อระดับแก๊สสูงขึ้นถึงระดับที่แต่ละคนตั้งไว้ และแจ้งอีกครั้งเมื่อค่ากลับเป็นปกติ

## 2. Gemini (สรุปสัปดาห์ด้วย AI)

1. เข้า <https://aistudio.google.com/apikey> แล้วกด Create API key
2. ตั้งค่าใน Cloudflare:

```powershell
npx.cmd wrangler pages secret put GEMINI_API_KEY --project-name gasguard-bu
```

3. (ไม่บังคับ) เลือกรุ่นใน `wrangler.toml`: `GEMINI_MODEL = "gemini-flash-lite-latest"` (ค่าเริ่มต้น)

**การทำงาน:**
- ระบบส่งให้ AI เฉพาะ **ตัวเลขสรุป 7 วัน** เท่านั้น (ค่าสูงสุดรายวัน, จำนวนชั่วโมงที่เกินเกณฑ์, ช่วงเหตุการณ์) ไม่ส่งชื่อหรืออีเมล
- เก็บผลสรุปไว้ 6 ชั่วโมง
- **ระดับอันตรายตัดสินด้วยกฎตัวเลขเสมอ** AI แค่เรียบเรียงคำ

## 3. ผู้ใช้แต่ละแบบ

| บทบาท | เข้าใช้ได้ | สร้างอย่างไร |
|---|---|---|
| เจ้าของบ้าน | หน้าหลัก แปลนบ้าน ประวัติ บ้านของฉัน, เชิญสมาชิก, แก้แปลน | ผู้ดูแลระบบสร้างบัญชีแล้วเพิ่มเป็น "เจ้าของ" ของสถานที่ |
| สมาชิก / พนักงาน | ดูสถานะ, แปลน (ดูอย่างเดียว), รับแจ้งเตือน, กดรับทราบ | เจ้าของบ้านส่ง **ลิงก์เชิญ** ให้ |
| ช่างติดตั้ง | งานของฉัน, ขั้นตอนติดตั้ง 5 ขั้น, วางแปลน, บันทึกค่า Ro | ผู้ดูแลระบบสร้างบัญชีบทบาท "ช่างติดตั้ง" แล้วมอบหมายงานในแท็บ "งานช่าง" |
| ผู้ดูแลระบบ | ภาพรวมทุกสถานที่, เพิ่มสถานที่/บอร์ด/ออก device key, ผู้ใช้และสิทธิ์, งานช่าง และดูบ้านใดก็ได้ | ตั้งบทบาท `admin` |
