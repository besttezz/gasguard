ทั่วไป · ความปลอดภัย · ข้อมูล

GasGuard v2.0 · ข้อมูลถูกเก็บในเครื่องของคุณ (localStorage) เท่านั้น

คู่มือใช้งานฉบับย่อ

1. ใช้งานทันที (โหมดจำลอง)

เปิดเว็บแล้วใช้ได้เลย ข้อมูลถูกจำลองเพื่อสาธิต เหมาะกับการนำเสนอหน้าชั้นเรียน — เปลี่ยนสถานการณ์ได้ที่ ตั้งค่า → แหล่งข้อมูล → จำลอง

2. ต่อเซ็นเซอร์จริง (ESP32 + MQ-2/MQ-5/MQ-135)

มี 2 วิธี เลือกอย่างใดอย่างหนึ่ง

  • REST API — ให้บอร์ดส่งค่าไปเก็บที่เซิร์ฟเวอร์ (ตัวอย่างในโฟลเดอร์ server/) แล้วตั้ง URL ในหน้าตั้งค่า
  • MQTT — บอร์ดส่งขึ้น broker (เช่น HiveMQ / EMQX) เว็บ subscribe ผ่าน WebSocket โดยตรง ไม่ต้องมีเซิร์ฟเวอร์ของเราเอง

รูปแบบข้อมูลที่เว็บรับได้:

{ "id": "kitchen-01", "ppm": 142, "temp": 31.5, "humidity": 62 }

ตัวอย่างโค้ดบอร์ดอยู่ในไฟล์ firmware/gasguard_esp32.ino

3. ติดตั้งเป็นแอปบนมือถือ / ไอแพด

  • iPhone / iPad: เปิดใน Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
  • Android: เปิดใน Chrome → เมนู → "ติดตั้งแอป"

บน iOS การแจ้งเตือนจะทำงานเมื่อเพิ่มลงหน้าจอโฮมแล้วเท่านั้น

4. คำเตือนด้านความปลอดภัย

ระบบนี้เป็นเครื่องมือช่วยเฝ้าระวังและสื่อการเรียนรู้ ไม่ใช่อุปกรณ์นิรภัยที่ผ่านการรับรอง ห้ามใช้แทนเครื่องตรวจจับแก๊สมาตรฐานในพื้นที่เสี่ยง และควรมีระบบตัดแก๊ส/ระบายอากาศสำรองเสมอ
